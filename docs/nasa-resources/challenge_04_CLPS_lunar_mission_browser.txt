PROBLEM SUMMARY:
Build an intuitive tool that lets mission planners, educators, and the public
compare lunar South Pole landing sites and dates by visualizing Sun and Earth
positions relative to the horizon, assessing solar power potential and
direct-to-Earth communication windows.

====================================================================================================
SECTION 1: OFFICIAL NASA DATASETS & DATA PORTALS
====================================================================================================

1.1 LUNAR TOPOGRAPHY — LRO LOLA (Lunar Orbiter Laser Altimeter)
----------------------------------------------------------------------------------------------------
- Description: The gold standard for lunar elevation data. Gridded DEMs at
  resolutions from 64 ppd (global) down to 5 m/pixel at the South Pole.
- Products: Gridded Data Records (GDR), Point Data, Polar Stereographic DEMs
- South Pole Specialty: Researchers have created refined 5 m/pixel DEMs for
  high-priority South Pole landing sites by co-adjusting LOLA tracks
  (horizontal accuracy ~10-20 cm).
- Access Portal: PDS Geosciences Node
  → https://pds-geosciences.wustl.edu/missions/lro/lola.html
- Direct Download: https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/
- Format: IMG/PDS3, GeoTIFF
- File Sizes: Individual tiles ~50-500 MB; full global dataset ~100+ GB

1.2 LUNAR RECONNAISSANCE ORBITER CAMERA (LROC)
----------------------------------------------------------------------------------------------------
- Description: High-resolution optical imagery of the lunar surface.
  Narrow Angle Camera (NAC) at 0.5 m/pixel, Wide Angle Camera (WAC) at 100 m/pixel.
- Key Products: NAC DTMs (Digital Terrain Models), WAC mosaics, Apollo landing site imagery
- Access Portal: LROC Quickmap & PDS Imaging Node
  → https://quickmap.lroc.asu.edu/
  → https://wms.lroc.asu.edu/lroc/
- API: LROC WMS (Web Map Service) for tile-based imagery
  → Base URL: https://wms.lroc.asu.edu/lroc/

1.3 NASA NAIF SPICE KERNELS (Sun/Earth/Moon Ephemeris)
----------------------------------------------------------------------------------------------------
- Description: THE critical dataset for this challenge. SPICE provides precise
  geometric positions of the Sun, Earth, and spacecraft relative to the Moon
  at any point in time. Required for computing solar illumination angles and
  Earth visibility (line-of-sight communication windows).
- Toolkit: SPICE Toolkit (C, Fortran, IDL, MATLAB, Python via SpiceyPy)
- Python Binding: SpiceyPy → pip install spiceypy
- Generic Kernels (Sun, Earth, Moon positions):
  → https://naif.jpl.nasa.gov/pub/naif/generic_kernels/
- CLPS Mission-Specific Kernels:
  → https://naif.jpl.nasa.gov/pub/naif/pds/
  → Task Order kernels: TO2AB (Astrobotic), TO2IM (Intuitive Machines), TO19D
- Planetary Ephemeris: DE440 (latest) or DE421
  → https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/
- Lunar Frame Kernels (Moon orientation/libration):
  → https://naif.jpl.nasa.gov/pub/naif/generic_kernels/fk/satellites/
  → moon_080317.tf, moon_assoc_me.tf
- Leap Seconds Kernel: naif0012.tls
- Format: Binary SPK, CK, PCK files + text FK, IK, SCLK files

1.5 LUNAR QUICKMAP (Interactive Lunar GIS)
----------------------------------------------------------------------------------------------------
- Description: NASA/ASU interactive web-based lunar mapping tool with
  dozens of data layers including illumination, slope, roughness, hydrogen.
- Features: Layer toggle, measurement tools, crater identification, 3D view
- Access: https://quickmap.lroc.asu.edu/
- Data Layers Include:
  → LOLA Elevation (color-coded)
  → LOLA Slope
  → Diviner H-parameter (thermal roughness)
  → Mini-RF radar (subsurface ice indicators)
  → Neutron spectrometer (hydrogen/water ice proxy)
  → Permanently Shadowed Regions (PSR) maps

SECTION 2: OPEN-SOURCE TOOLS, LIBRARIES & GITHUB REPOS
====================================================================================================

2.1 SpiceyPy (Python SPICE Bindings)
- Description: Python wrapper for NASA NAIF SPICE toolkit
- Install: pip install spiceypy
- GitHub: https://github.com/AndrewAnnex/SpiceyPy
- Documentation: https://spiceypy.readthedocs.io/
- Key Functions:
  → spkezr() — Get position of Sun/Earth relative to Moon at any time
  → subpnt() — Find sub-solar and sub-Earth points on Moon surface
  → illumf() — Compute illumination angles at a surface point
  → sincpt() — Compute ray-surface intersection (line-of-sight check)

2.2 Celestial Mapping System (CMS)
- Description: NASA-developed platform for generating virtual 3D globes
  with sunlight shading, line-of-sight analysis, and terrain profiling.
- Status: Check NASA Software Catalog for availability

2.3 Cesium / CesiumJS (3D Geospatial Visualization)
- Description: Open-source JavaScript 3D globe and map engine. Can be
  adapted for lunar surfaces with custom terrain providers.
- Website: https://cesium.com/
- GitHub: https://github.com/CesiumGS/cesium
- Relevance: Perfect for building the 3D lunar South Pole browser UI

2.4 Three.js (WebGL 3D Engine)
- Description: Most popular JavaScript 3D library. Can render LOLA
  elevation data as 3D terrain meshes with real-time lighting.
- Website: https://threejs.org/
- GitHub: https://github.com/mrdoob/three.js

2.5 NASA Ames Stereo Pipeline (ASP)
- Description: Open-source photogrammetry toolkit for generating DTMs
  from stereo imagery pairs (LROC NAC, HiRISE).
- GitHub: https://github.com/NeoGeographyToolkit/StereoPipeline
- Use Case: Generate custom high-res terrain for specific landing sites

SECTION 6: STRATEGY & ARCHITECTURE RECOMMENDATIONS
====================================================================================================

6.1 CORE TECHNICAL ARCHITECTURE
- Frontend: Three.js or CesiumJS for 3D lunar terrain rendering
- Ephemeris Engine: SpiceyPy compiled to WebAssembly (OR server-side Python
  API serving precomputed Sun/Earth vectors via REST)
- Terrain Data: LOLA 5m/pixel South Pole DEM converted to mesh/heightmap
- Time Controls: Interactive scrubber spanning 2024-2030 with 1-hour granularity
- Visualization: Real-time shadow casting based on Sun azimuth/elevation at
  each candidate landing site

6.2 KILLER DIFFERENTIATORS
- "Mission Opportunity Finder": Automated algorithm that identifies multi-day
  continuous sunlight windows + Earth line-of-sight for any South Pole site
- Side-by-Side Site Comparison: Select 2-4 candidate sites and overlay their
  illumination/comms profiles on a single timeline
- Export/Share: Generate mission planning reports (PDF) with illumination
  charts for specific dates

6.3 DATA PIPELINE
1. Download LOLA South Pole DEM (5m/pixel GeoTIFF)
2. Load SPICE generic kernels (planetary ephemeris, lunar orientation)
3. For each time step (hourly, 2024-2030):
   a. Compute Sun vector relative to Moon center (spkezr)
   b. Compute Earth vector relative to Moon center (spkezr)
   c. For each surface point (lat/lon grid at South Pole):
      - Ray-trace Sun vector against terrain → illuminated or shadowed
      - Ray-trace Earth vector against terrain → comms or blocked
4. Store results as time-indexed illumination/visibility matrices
5. Serve via API or precomputed tiles to frontend
