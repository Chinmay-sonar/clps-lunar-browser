# Codyseey Documentation & Technical Archives

This directory holds the official NASA challenge materials, research manifests, presentation decks, and visual assets for **Codyseey — NASA CLPS Lunar Mission Browser**.

## Subdirectories

- **[`nasa-resources/`](./nasa-resources/)**:
  - `challenge_04_CLPS_lunar_mission_browser.txt`: Official NASA Space Apps Challenge 4 problem dossier and requirements.
  - `MASTER_RESOURCES_AND_TECH_MANIFEST.md`: Complete dataset index (LRO LOLA, LROC NAC, JPL SPICE DE440/441 ephemeris, Moon Trek).
  - `UI_UX_ARSENAL_AND_PREPARATION.md`: Aerospace dark-tech design architecture, typography, color palettes, and motion principles.
  - `Chinmay understanding.txt`: Project architectural notes and domain breakdown.

- **[`presentation/`](./presentation/)**:
  - `Codyseey_CLPS_Lunar_Mission_Browser_Final.pptx`: Official competition pitch deck.
  - `create_presentation.py` & `build_minimal_demo_deck.py`: Python automation scripts used to compile and export slides.

- **[`screenshots/`](./screenshots/)**:
  - High-resolution showcase captures covering the 3D Moon digital twin, VIPER surface traversal, Solstice timeline controller, and scientific analytics drawer.
